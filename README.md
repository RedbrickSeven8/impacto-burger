# 🍔 Impacto Burger - Sitio Web Oficial & Menú Interactivo

Sitio web oficial y menú digital interactivo para **Impacto Burger**.

🌐 **Sitio Web en Vivo:** [https://impactoburger.surge.sh](https://impactoburger.surge.sh)

---

## 🚀 Despliegue Continuo (CI/CD)
Cualquier cambio o edición que realices directamente en los archivos de este repositorio de GitHub se despliega de forma automática en la URL de Surge:
- **URL de Producción:** [https://impactoburger.surge.sh](https://impactoburger.surge.sh)
- **Workflow:** `.github/workflows/deploy.yml`

---

## 🛠️ Características Principales
- **Animación Automática & Hover:** Transición de capas de la *Onion Burger* (`Onion Burguer 1.png` ➔ `Onion Burguer - explode.jpg`) al cargar y al interactuar.
- **Acceso Directo:** Clic en la animación del Hero para desplazarse instantáneamente al menú.
- **Mobile First:** En dispositivos móviles la animación del producto estrella se prioriza en la parte superior.
- **Filtro de Menú Interactivo:** Categorías dinámicas (Hamburguesas, Especialidades, Infantil, Acompañantes).
- **Indicador de Estado en Vivo:** Horario y apertura en tiempo real.
