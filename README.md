# Impacto Burger - Sitio Web Oficial

Sitio web oficial y menú interactivo de **Impacto Burger**.
Desarrollado con Tailwind CSS, animaciones interactivas, vista móvil optimizada y carga lazy para máximo rendimiento.

- 🍔 **Especialidad:** Onion Burger con animación de capas al cargar.
- 📱 **Mobile First:** En dispositivos móviles, la animación del producto estrella se visualiza antes del copy.
- 🚀 **Despliegue:** https://impactoburger.surge.sh
